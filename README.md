# Japan Tour Sign-Up Form

A simple, responsive sign-up form for a Japan tour experience. The page uses plain HTML, CSS, and JavaScript with client-side form validation.

## Features

- First and last name fields
- Email and phone number fields
- Password and password confirmation fields
- Input validation and inline error messages
- Responsive layout for desktop and mobile


## Project files

- `index.html` — Page structure and form
- `styles/style.css` — Layout, styling, and responsive design
- `scripts/script.js` — Form validation and submission behavior
- `assets/` — Images and icons used by the page

> This project is a front-end demo. It does not connect the form to a backend or database.
